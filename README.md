# Coyote 波形绘制器 (PulseWaveStudio)

DG-Lab Coyote 设备的波形可视化编辑工具，支持手绘、函数生成、素材拼接和 JSON5 导入导出。

## 快速开始

### 从零构建环境

需要 Python 3.10+（开发使用 3.13.5）。

```bash
# 1. 克隆仓库
git clone https://github.com/kswag72/PulseWaveStudio.git
cd PulseWaveStudio

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活虚拟环境
# Windows PowerShell:
.\venv\Scripts\Activate.ps1
# Windows CMD:
venv\Scripts\activate.bat

# 4. 安装依赖
pip install PyQt6 pyinstaller

# 5. 下载字体（见下方说明）

# 6. 运行程序
python main.py

# 7. (可选) 构建可分发 exe
python -m PyInstaller PulseWaveStudio.spec --clean
```

构建产出位于 `dist/PulseWaveStudio.exe`，单文件，无需安装 Python 即可运行。

### 字体安装

本项目使用 [Maple Mono](https://github.com/subframe7536/maple-font) 字体，因体积较大（20MB）未包含在仓库中，需手动下载：

1. 前往 [Maple Font Releases](https://github.com/subframe7536/maple-font/releases)
2. 下载 **MapleMono-NF-CN-unhinted** 压缩包
3. 解压后将 `MapleMono-NF-CN-ExtraBold.ttf` 复制到项目的 `src/fonts/` 目录下

```bash
# 确保目录存在
mkdir -p src/fonts

# 将字体文件放入
cp /path/to/MapleMono-NF-CN-ExtraBold.ttf src/fonts/
```

> 如果缺少字体文件，程序仍可运行但会回退到系统默认字体。

## 功能说明

### 1. 波形画布

画布分为上下两区：
- **上半区** — 间隔 (interval)，范围 10~1000，曲线颜色 `#ffde7d`
- **下半区** — 强度 (intensity)，范围 0~100，曲线颜色 `#ffe2e2`

直接用鼠标在画布上拖动绘制波形。步骤数通过「小节数」滑条调整（1~320）。

### 2. 单步精确设置

选择步骤编号，输入间隔/强度值，点击「设置」写入单个步骤。步骤选择与画布双向同步。

### 3. 批量设置

通过双端范围滑条选择步骤范围，输入目标值，点击「批量设置间隔」或「批量设置强度」一键填充。

### 4. 函数生成器

支持 10 种函数类型，可分别生成强度或间隔波形：

| 函数 | 说明 | 关键参数 |
|------|------|----------|
| 正弦波 | 平滑周期波 | 周期、振幅、偏移 |
| 方波 | 高低交替 | 周期、振幅、偏移 |
| 锯齿波 | 线性上升后归零 | 周期、振幅、偏移 |
| 三角波 | 线性上升再下降 | 周期、振幅、偏移 |
| 幂函数 | t^n 曲线 | 指数(幂次)、系数、偏移 |
| 多项式 | at^2 + bt 曲线 | 指数(线性项系数)、系数(二次项系数)、偏移 |
| 指数函数 | 指数增长 | 指数(增长率)、系数、偏移 |
| 对数函数 | 对数增长 | 指数(曲线陡度)、系数、偏移 |
| 指数衰减 | 快速上升后趋平 | 指数(衰减率)、系数、偏移 |
| S形曲线 | 缓-急-缓过渡 | 指数(过渡陡度)、系数、偏移 |

使用范围滑条限定函数应用的步骤区间。

### 5. 素材库

- **导入**: 将 `pulse.json5` 文件拖入窗口
- **加载**: 点击素材名称加载到画布
- **添加到序列**: 点击 `+` 按钮
- **删除**: 点击 `x` 按钮
- **导出**: 点击「导出资产库」保存整个库

### 6. 拼接序列

将多个素材和静默间隔拼接为一条完整波形：
1. 从素材库点击 `+` 添加波形片段
2. 点击「插入静默(ms)」添加空白间隔
3. 点击序列中的标签可移除该片段
4. 点击「序列合成入库」将拼接结果保存为新素材
5. 「预览代码」查看导出格式，「导出 JSON5」保存文件

### 7. 一键平滑

对当前画布上的间隔和强度曲线进行平滑处理（相邻点加权平均）。

## JSON5 数据格式

导入文件为 DG-Lab pulse 格式：

```json5
[
  {
    id: 'abc123',
    name: '示例波形',
    pulseData: [
      '0A0A0A0A32323232',  // 间隔=0x0A(10), 强度=0x32(50)
      '1E1E1E1E64646464',  // 间隔=0x1E(30), 强度=0x64(100)
      // ...
    ]
  }
]
```

每条 pulseData 为 16 字符 hex 字符串：
- 前 2 位 × 4 = 间隔 (重复 4 次)
- 后 2 位 × 4 = 强度 (重复 4 次)

## 键盘与交互

| 操作 | 说明 |
|------|------|
| 鼠标拖动画布上半区 | 绘制间隔曲线 |
| 鼠标拖动画布下半区 | 绘制强度曲线 |
| 拖入 .json5 文件到窗口 | 导入素材 |
| 点击序列标签 | 移除该片段 |
